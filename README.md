# FinanceBuddy 💰

A simple and clean web app to track your income and expenses.

## Features

* Add, edit and delete transactions
* Filter and sort transactions
* Visual charts for income and expenses
* Export transactions as CSV
* Local storage support (no backend needed)

## Tech Used

* HTML
* CSS
* JavaScript
* Chart.js

## How to Use

1. Open `index.html` in your browser
2. Click **Add Transaction**
3. Fill the details and save
4. View reports and charts instantly

## Notes

* Data is stored in your browser (localStorage)
* Clearing browser data will remove all transactions
